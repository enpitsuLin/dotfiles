# pc/ — Legacy Windows configuration (archived)

These PowerShell files (`setup.ps1`, `pc_profile.ps1`) are **old, unmaintained**
Windows (scoop-based) setup scripts, kept for historical reference only.

- They are **not** managed by chezmoi and are **not** applied on any machine.
- The active cross-platform setup (macOS + Linux) lives in the repo root and the `dot_*` directories.
- Consider deleting this directory once the historical reference is no longer needed.
